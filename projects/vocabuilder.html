VocaBuilder 3000

React Native Python Gemini API AsyncStorage
Play Store'da Gör
Platform: Android
Kategori: Eğitim & Sınav Hazırlık
Mimari: React Native & Python
Durum: Google Play'de Canlı

Proje Hakkında

VocaBuilder 3000, Oxford'un belirlediği en sık kullanılan 3000 İngilizce kelimenin hızlı bir şekilde pratik yapılabilmesi ve kalıcı olarak öğrenilmesi amacıyla geliştirilmiş bir mobil uygulamadır. YDS, YÖKDİL, YKS-DİL ve TOEFL sınavlarına hazırlanan kullanıcıların kelime dağarcığını güçlendirmeyi hedefler.

Öne Çıkan Özellikler

Oxford 3000 Veri Seti

En kritik 3000 kelimenin seviyelerine göre filtrelendiği kapsamlı akademik sözlük altyapısı.

Boşluk Doldurma & Test

Bağlamsal öğrenmeyi hızlandıran boşluk tamamlama ve çoktan seçmeli dinamik test modülleri.

Örnek Cümleler & Anlamlar

Her kelime için özel hazırlanmış net tanımlar ve günlük/akademik kullanım örnekleri.

Favoriler Havuzu

Kullanıcının zorlandığı veya özel olarak tekrar etmek istediği kelimeleri tek tıkla kaydetme imkanı.

Hata & Yanlış Analizi

Yanlış bilinen sözcükleri hafızaya alıp sonradan pratik yapmaya olanak tanıyan "Hatalarım" alanı.

Yapay Zeka Destekli Pipeline

Python ve Gemini API ile regex tabanlı veri temizleme, ID eşleme ve otomatik veri üretimi.

Geliştirme Süreci ve Teknik Detaylar

  • Veri Pipeline & AI: Python ve Gemini API promptları ile Oxford 3000 verisi Regex ile temizlenmiş, foreign key mantığıyla çok dilli JSON veritabanı inşa edilmiştir.
  • Performans Optimizasyonu: 3000 kelimelik geniş veri setinin sıfır gecikmeyle akması için React Native FlatList render optimizasyonu uygulanmıştır.
  • Çevrimdışı Kalıcılık: "Favoriler" ve "Hatalarım" gibi kullanıcı verilerinin tamamen offline çalışabilmesi amacıyla AsyncStorage entegrasyonu sağlanmıştır.
  • Navigasyon & UX: React Navigation ile ekranlar arası yumuşak geçişler ve React Hooks ile anlık doğru/yanlış durum geri bildirimleri.
